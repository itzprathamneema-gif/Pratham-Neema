# Pratham Neema

A multiplayer racing game developed in Unity 3D.

## Project Structure
This project includes various components for a complete racing game, including animations, characters, cars, and gameplay scripts.

### Folder Structure
- **Assets**: Contains all game assets including characters, cars, animations, and scripts.
- **ProjectSettings**: Unity project settings files.
- **Documentation**: Game design and art style documents.

## Getting Started
- Clone the repository.
- Open the project in Unity 3D.
- Make sure to build the project for multiplayer compatibility.
